# Issue tracker contract

The canonical tracker is `Reid-Surmeier/qwen-image-pipeline` on GitHub.

- One specification Issue defines the version outcome and owns its native sub-issues.
- Each implementation ticket is independently testable and names its body blockers.
- Native GitHub blocked-by relationships are the executable dependency graph; prose copies explain but do not replace it.
- The next frontier is an open `ready-for-agent` ticket with every blocker closed.
- Ticket comments record exact commits and verification evidence; accepted requirements belong in the Issue body.
- The one draft build pull request is the version changelog and review surface. Tickets do not each get an owner-facing pull request.
